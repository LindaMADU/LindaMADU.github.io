01 ELT · Analytics Engineering

ELT Pipeline — dbt + Snowflake Analytics Platform

A production-grade ELT pipeline that centralises data from five source systems into a Snowflake data warehouse, modelled with dbt and served to business stakeholders via Power BI.

🔴 The Problem

Business reporting relied on fragmented spreadsheets pulled from five disconnected source systems, leading to inconsistent numbers, long manual refresh cycles, and zero data lineage visibility.

🟢 The Approach

Designed a three-layer dbt architecture (staging → intermediate → marts) on Snowflake, orchestrated daily via Airflow DAGs. Implemented dbt tests and documentation to enforce data quality and lineage throughout.

02 Streaming · Real-Time

Real-Time Analytics Pipeline

A streaming data pipeline that ingests high-frequency event data, processes it in near real-time, and delivers live dashboards for operational monitoring and business decisions.

🔴 The Problem

Operational teams were working off batch reports with 24-hour delays, causing them to react to issues after the fact rather than catching anomalies as they happened.

🟢 The Approach

Built an event-driven streaming pipeline using Azure Event Hubs for ingestion, PySpark Structured Streaming for transformation, and Snowflake Dynamic Tables for continuous materialisation. Power BI auto-refreshes every 15 minutes.

03 Migration · Cloud Modernisation

Data Warehouse Migration to Snowflake

Full migration of a legacy on-premise data warehouse to Snowflake on Azure, including schema redesign, historical data reload, and cutover with zero business downtime.

🔴 The Problem

An ageing on-premise SQL Server warehouse was becoming a bottleneck — slow query performance, costly maintenance, inability to scale, and no self-serve capability for analysts.

🟢 The Approach

Audited the existing schema, redesigned table structures for Snowflake's columnar engine, built incremental and full-load pipelines in Azure Data Factory, validated data fidelity at each stage, and executed a phased cutover with rollback capability.

04 Orchestration · Azure

Azure Data Factory Enterprise Pipeline

A scalable, parameterised ADF pipeline framework ingesting data from REST APIs, flat files, and relational databases into a centralised Azure Data Lake, with automated quality checks at each stage.

🔴 The Problem

Multiple teams maintained siloed, bespoke ingestion scripts with no standard monitoring, inconsistent error handling, and no central visibility into pipeline health or data freshness.

🟢 The Approach

Built a reusable, configuration-driven ADF pipeline framework with parameterised templates covering REST, SFTP, and JDBC sources. Added a metadata-driven control table, automated alerting via Logic Apps, and a Power BI pipeline health dashboard.

05 Analytics · Insights

Customer Behaviour Analytics Platform

An end-to-end analytics solution transforming raw customer event data into actionable segmentation models and executive dashboards, enabling data-driven marketing and product decisions.

🔴 The Problem

The business had rich customer interaction data sitting unused in raw log files. Marketing and product teams had no reliable way to understand customer segments, churn risk, or product engagement patterns.

🟢 The Approach

Processed raw event logs with PySpark on Azure Databricks, built RFM (Recency, Frequency, Monetary) segmentation models in Python, stored clean outputs in Snowflake, and delivered interactive Power BI dashboards for business stakeholders with drill-through capability.
