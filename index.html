🏆 Step 3 — Add / Upload Certifications

Option B — Upload PDF to GitHub Repo
Upload your cert PDF to your GitHub repo, then link it directly.
href="certs/snowpro-core.pdf"
Create a certs/ folder in your repo and upload all PDF certificates there.
Add a New Certification
Copy an existing cert card block in the HTML, paste it after the last cert card, and update the icon, name, issuer, status and href link.
